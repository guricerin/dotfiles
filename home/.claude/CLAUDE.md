# 返答の言語

- 返答は日本語で書く。コマンド、パス、ファイル名、コード、エラーメッセージは英語のまま書く

# スキルを作るとき

- SKILL.md を新しく書くときは（skill-creator を使う場合も含めて）、`~/.claude/templates/SKILL.md` を雛形にし、見出しの構成を変えない
- `{{必須: ...}}` はすべて埋める。該当するものがない項目は「該当なし（理由: …）」と書く
- 項目を埋めるための情報が足りない、またはユーザーの説明に矛盾がある場合は、推測で埋めずに止まってユーザーに聞く

# 会話の区切り

- 作業がひと区切りついたとき（PR のマージ後の片付けが終わった、話題ががらっと変わるなど）は、`/clear` で新しい会話にするようすすめる。会話が長くなると前半が要約され、細かいところが抜けやすくなるため
- 残したいことがあれば、`/clear` の前に pkb などのファイルに書くよう声をかける

# シェル

- シェルは zsh。`=` で始まる語は引用符で囲む（例: 区切りは `echo '----'`）。`echo ====` のように書くと、zsh が `=` で始まる語をコマンド名として展開しようとし、`=== not found` で止まって、後ろのコマンドが実行されない

# PR を作るとき

- `gh pr create` には必ず `--draft` を付ける。レビューの準備ができてから本人が ready にするため。仕事のリポジトリでは付け忘れると hook に止められ、作り直しになる
